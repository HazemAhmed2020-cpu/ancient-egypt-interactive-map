# 🏺 خريطة الحضارة المصرية القديمة — موقع تفاعلي

مشروع موقع ويب تفاعلي (بالعربية) يستعرض أشهر مواقع الحضارة المصرية القديمة على خريطة حقيقية،
مناسب لمشروع جامعي في مادة الحضارة/تطوير الويب.

## ✨ المميزات
- **خريطة تفاعلية حقيقية** (Leaflet) بطبقتين: قمر صناعي + خريطة طرق، مع تكبير/تصغير كامل.
- **15 موقعاً** مصنفاً: معابد (٨ — ومنها دندرة) – أهرامات (٢) – مسلات (١) – مقابر (٣) – متاحف (١): الجيزة (ومنها مقبرة ميريس عنخ الثالث)، سقارة، الكرنك، الأقصر، الدير البحري، إدفو، كوم أمبو، فيلة، المسلة الناقصة بأسوان، أبو سمبل، مقابر منّا (TT69) ورمسيس السادس (KV9) وميريس عنخ الثالث (G 7530)، **والمتحف المصري الكبير** — أكبر متحف في العالم مخصص لحضارة واحدة، بجولة Matterport حقيقية داخل قاعة كنوز توت عنخ آمون.
- **شرح صوتي بالعربية** يبدأ تلقائياً عند الضغط على أي موقع (ملفات MP3 داخل المشروع).
- **جولة 360° داخل الموقع** لكل المواقع الأحد عشر: اسحب للدوران، وعجلة الفأرة للتقريب، ونقاط ذهبية على أجزاء كل موقع.
- **بانورامات وجولات 360° حقيقية لكل المواقع** تُعرض داخل الموقع:
  - بانورامات كروية حقيقية عبر منصة 360Cities (كرنك، الأقصر، الدير البحري، إدفو، كوم أمبو، فيلة، الجيزة، المسلة الناقصة) — تضمين مجاني للاستخدام غير التجاري، وحقوق كل بانوراما لمصورها (Hamblin، Kottmann، Attef، ElDardiry، Di Mattia).
  - جولات مسح ضوئي ثلاثي الأبعاد عبر Matterport (تُعرض عبر منصة mpembed): معبد أبو سمبل، مقبرة منّا، ومقبرة الملكة ميريس عنخ الثالث.
  - جولات 3D متعددة الأماكن لكل المواقع (15): التنقل بين مشاهد المدخل/البهو/العمق بحلقات برتقالية مرقّمة + خريطة أماكن مصغّرة + شريط تحكم كامل (مشي/لفّ/تقريب/دوران تلقائي/إعادة/ملء شاشة).
  - ملاحظة: روابط Matterport الأصلية لمجمع زوسر ومقبرة منّا أصبحت غير متاحة من مالكيها، فاستُبدلت ببدائل حقيقية (بانوراما 360Cities لزوسر، ومقبرة رمسيس السادس الجديدة بجولتها الداخلية).
  - رابط أرشيف الجيزة QTVR (1200 بانوراما) التابع لمتحف بوسطن (MFA) في كارت الجيزة.
- **أجزاء كل موقع** معروضة كنقاط ذهبية داخل الجولة 360° وفي كارت الموقع، مع وصف كل جزء.
- **أبرز الأحداث والتواريخ** لكل موقع، وفلاتر للأنواع (معابد/أهرامات/مسلات)، وقائمة انتقال سريع.

## ▶️ طريقة التشغيل
1. **الأبسط:** افتح ملف `index.html` مباشرة في المتصفح (يلزم اتصال إنترنت لظهور الخريطة والصور من طبقات الخريطة).
2. **الأفضل (خادم محلي):**
   ```
   cd ancient-egypt
   python -m http.server 8000
   ```
   ثم افتح: `http://localhost:8000`

## 📁 هيكل المشروع
```
ancient-egypt/
├── index.html          ← الموقع كامل (HTML + CSS + JavaScript)
├── vendor/             ← مكتبة Leaflet (خريطة تفاعلية)
└── assets/
    ├── img/            ← صور المواقع وصورة الغلاف
    ├── pano/           ← صور البانوراما 360° (equirectangular)
    └── audio/          ← الشروح الصوتية العربية (MP3)
```

- **عصا تحكم المشي (جولة 3D)**: ▲ امشي جوا الأثر • ▼ ارجع خطوة • ◀ ▶ لِفّ بعينك يمين وشمال — من الشاشة أو بأسهم الكيبورد (WASD)، مع إحساس "خطوة الدخول" عند الانتقال بين الأماكن.

## 🛠️ التقنيات
- HTML5 + CSS3 + JavaScript خالص (بدون أطر عمل).
- مكتبة **Leaflet 1.9.4** للخريطة (محلية داخل المشروع).
- عارض بانوراما 360° مكتوب من الصفر بـ **WebGL** (بدون مكتبات خارجية).
- طبقات خريطة: Esri World Imagery + OpenStreetMap.

## 📚 ملاحظات المحتوى
- المعلومات التاريخية مبنية على المراجع الشائعة لعلم المصريات (أرقام وتواريخ تقريبية).
- الصور الفوتوغرافية: من مصادر ويب عامة، والبانورامات مولدة بالذكاء الاصطناعي لأغراض العرض التعليمي.
- الأصوات: توليد صوتي عربي فصيح.
